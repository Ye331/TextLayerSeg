# 金字塔瓶颈消融 V1 预注册

## 研究问题

当前语义金字塔中的哪些部分产生了性能增益，哪些部分限制了进一步提升？在提出新模块之前，本实验先对金字塔结构进行逐步分解。

## 冻结实验协议

- 仅使用无泄漏的 grouped fit/dev 划分；
- 训练集：120 个源页面、85,408 个样本；
- 开发集：14 个源页面、7,361 个样本；
- 随机种子 2026，4 张 RTX 3090，global batch 8，RGB 768；
- 完成 8,192 次成功的优化器更新，不允许跳过更新；
- 在 step 2048、4096、6144、8192 对完整开发集进行原分辨率评测；
- 模型选择规则：优先最大化 mIoU，随后依次比较 macro-F1、OV-F1 和更早 step；
- 不使用 official validation 或 official test。

## 递增消融变体

所有变体使用相同的 ImageNet 预训练 ResNet-50 和训练协议，并关闭 S/W 特征反馈与 S/W 辅助监督。

1. `c2`：仅投影并残差细化 ResNet C2；
2. `fpn`：使用标准 C2-C5 自顶向下 FPN，C5 采用 1×1 横向投影；
3. `fpn_context`：将 C5 的 1×1 投影替换为固定的多膨胀率上下文模块；
4. `allscale`：把自顶向下生成的 P2-P5 特征统一到 P2 分辨率后直接拼接；
5. `full`：在相同的全尺度拼接之前，加入已有的自顶向下/自底向上残差细化。只有在 state key、初始化哈希和前向输出完全一致后，才复用此前已经完成的 clean P 分支。

每个分支均使用两个辅助分类器和相同的辅助损失权重。对于 `c2` 分支，两个辅助分类器均读取 C2，避免在去除金字塔时同时无意去除深监督。

## 结果解释规则

- `fpn - c2`：多尺度自顶向下融合的贡献；
- `fpn_context - fpn`：深层上下文模块的贡献；
- `allscale - fpn_context`：全尺度直接读取的贡献；
- `full - allscale`：双向残差细化的贡献。

本实验属于诊断性消融。不能仅凭某个组件获得正向边际增益，就将其称为新颖方法。报告时同时记录参数量、实际获得梯度的参数量、延迟和显存峰值。

## 停止规则

在该消融链条识别出明确的剩余瓶颈之前，不引入新的架构机制。如果 C2 已能解释大部分性能，则下一步应研究高分辨率表征，而不是尺度路由；如果多个层级均具有独立贡献，则可以进一步研究尺度融合；如果主要增益来自上下文，则下一步应研究长距离上下文建模。
