# 验证范围与证据边界

## 原项目中已经完成的验证

- 清理后的 FPN+Context 前向输出与最终选中的实验分支一致；
- 完整发布模型包含 34,737,868 个可训练参数；
- 前向 logits、损失、反向梯度和分类器梯度均为有限值；
- 最终记录的内部 grouped-dev 结果为 mIoU 0.779968、OV IoU 0.639459。

## 上述结果对应的实验协议

- 随机种子：2026；
- 训练集：120 个源页面、85,408 个样本；
- 分组开发集：14 个无交集源页面、7,361 个样本；
- RGB 768、global batch 8、4 张 RTX 3090；
- 8,192 次成功的优化器更新；
- checkpoint 依次按照 mIoU、macro-F1、OV-F1 和更早 step 选择；
- 未使用 official validation 和 official test。

## 本公开包尚未验证的内容

- 额外随机种子的复现结果；
- 一次性封存 official test 结果；
- 跨数据集或真实场景泛化；
- OCR/CER 改善；
- 推理速度、显存峰值或实时性能；
- SOTA 状态。

由于数据集和训练 checkpoint 未包含在公开包中，使用者无法仅凭本压缩包独立复现已记录的 benchmark 数值。玩具数据流程只能验证软件执行和数据接口，不能验证模型精度。

公开的 `scripts/train.py` 是精简单进程参考训练器，省略了原始分布式尺度鲁棒增强流程，因此不得将其描述为完整 benchmark 复现脚本。

## 发布包检查结果

- 所有 Python 文件均通过语法编译检查；
- 所有 JSON 和 TOML 元数据均可正常解析；
- 项目可在不解析运行时依赖的情况下成功构建 Python wheel；
- 玩具数据生成器能够产生合法 manifest、图像和四类掩码；
- 发布文本中未发现私有本地路径、服务器路径或疑似凭据内容。

本地打包环境没有安装 PyTorch，因此新组装压缩包没有在该环境中重新执行 tensor 单元测试。GitHub Actions 会安装声明的依赖，并执行 `pytest` 和合成前向/反向 smoke test。模型核心仍保留上述原项目中的有限前向与反向验证记录。
